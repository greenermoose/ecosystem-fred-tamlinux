Choosing the Base Operating System

← Back to Ecosystem Index

Every Linux distribution makes specific engineering trade-offs regarding packaging, init systems, release cadences, and system architecture. Tamlinux evaluated 12 distributions before setting its long-term roadmap.

1. The Current Base: Arch Linux (0.x)

Tamlinux's active daily development workstation runs on Arch Linux:

  • Why Arch Today: Arch provides the newest Linux kernels, Mesa graphics drivers, Qt 6 toolkits, and Wayland protocols. Its rolling release ensures that development is never constrained by outdated compilers.
  • Packaging: Arch uses Pacman with simple PKGBUILD recipes. Tamlinux manages locally patched software through a dedicated [local-patches] repository listed first in /etc/pacman.conf.
  • Why Moving: Arch's tight coupling to systemd and occasional packaging churn conflict with Tamlinux's long-term goal of an unbloated, non-systemd system.

2. The Selected Target: Void Linux (1.2+)

Tamlinux selected Void Linux as its target independent base (Decision D68, D126):

  • True Independence: Void is an independent distribution built from scratch, not a downstream derivative of Debian or Red Hat.
  • Native runit Init: Void uses runit for service supervision, eliminating the massive complexity and background daemon footprint of systemd.
  • The XBPS Package System: Implemented in fast, clean C, XBPS provides atomic transactions and clean chroot-based source package builds via xbps-src.
  • glibc and musl Options: Void maintains parallel architectures for both standard glibc and ultra-lightweight musl libc.
  • Tamlinux Custody: Tamlinux will host its own signed package repository and maintain xbps-src templates permanently in the project tree.

3. The Designated Fallback: antiX Linux Core

If Void Linux presents unexpected showstoppers during milestone 1.2 hardware testing, Tamlinux will deploy on antiX Linux Core:

  • Proven Hardware Longevity: antiX is specifically engineered to run gracefully on older, low-resource hardware.
  • systemd-Free Debian Base: Combines the massive package library of Debian with a lightweight, systemd-free init running runit.
  • Ultra-Low Memory Baseline: antiX Core idles in under 150 MB of RAM.

4. Other Evaluated Distributions

  • Debian: The universal upstream foundation. While conservative releases make it slow for bleeding-edge desktop development, its packaging standards remain the gold standard.
  • Alpine Linux: Ultra-minimal container OS based on musl and BusyBox. Proves how small a Linux base can be, but OpenRC and BusyBox differences make it less ergonomic for a daily graphical workstation.
  • Puppy Linux & Tiny Core: Demonstrations of extreme modularity (running entirely from RAM), informing Tamlinux's hardware longevity goals.
  • Gentoo: Source-based compilation allows ultimate optimization, but full source builds on vintage hardware are impractical for rapid updates.
