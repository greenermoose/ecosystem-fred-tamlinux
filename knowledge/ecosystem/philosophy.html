Free Software & Value per Watt

← Back to Ecosystem Index

Tamlinux is not just another desktop configuration; it is an expression of a philosophical stance on computing. It rests on the foundational principles of the Free Software movement, reinforced by a modern commitment to energy efficiency, hardware longevity, and human agency.

1. The Four Essential Freedoms

Tamlinux upholds the four essential freedoms articulated by the Free Software Foundation (FSF):

  • Freedom 0: The freedom to run the program as you wish, for any purpose.
  • Freedom 1: The freedom to study how the program works and adapt it to your needs.
  • Freedom 2: The freedom to redistribute copies to help others.
  • Freedom 3: The freedom to improve the program and release your improvements to the public.

Tamlinux distributes its own software under GPL-3.0-or-later. Copyleft guarantees that your freedom cannot be stripped away by proprietary forks or commercial enclosure.

2. Standards and Interoperability (freedesktop.org)

Sovereignty requires interoperability. If software traps you in proprietary data structures or undocumented protocols, freedom is an illusion. Tamlinux embraces freedesktop.org (XDG) standards:

  • Clean Directories: Configuration belongs in ~/.config, data in ~/.local/share, and runtime state in ~/.local/state. No hidden files cluttering your home root.
  • Standard Protocols: The desktop shell communicates with window managers using standard Wayland protocols (wlr-layer-shell, ext-workspace-v1), avoiding proprietary API locks.
  • Standard Formats: Applications are described by .desktop files; menus and icons follow shared specifications.

3. "Value per Watt": Energy-Conscious Computing

In modern computing, software often wastes massive amounts of electrical power and silicon cycles on useless background tasks. A typical modern OS runs dozens of daemons constantly polling network endpoints, indexing disks, and tracking user telemetry.

Tamlinux operates under the principle of "value per watt" (Decision D139):

  • Zero Polling: Software must sleep cleanly until an actual event occurs. Polling loops that prevent the CPU from entering low-power sleep states are treated as bugs.
  • Minimal Daemons: Services must earn their place in memory. If a feature can be implemented as an on-demand tool, it should not run as a permanent daemon.
  • Deterministic Execution: Computers should do what users tell them to do, with predictable resource costs and immediate responsiveness.

4. Supervised Human Agency

Computers exist to serve humans, not the other way around. In an era where software increasingly surrenders control to non-deterministic algorithms and opaque autonomous loops, Tamlinux insists on human agency:

  • AI tools are used as supervised assistants, directed by human engineers.
  • All AI code changes carry public provenance in AI_PROVENANCE.md.
  • Autonomous background agent loops (such as OpenClaw and Hermes) were retired from Tamlinux defaults (D139, D140) to keep system execution deterministic and energy-efficient.
