AI Coding Tooling & Human Agency

← Back to Ecosystem Index

Artificial Intelligence tools play a vital role in Tamlinux development. However, Tamlinux enforces strict ethical, operational, and efficiency policies regarding AI use.

1. Supervised Pair Programming vs Autonomous Daemons

In Decisions D139 and D140, Fred set a clear operational direction: favor deterministic programs that humans or supervised AI agents can control, minimize daemons and background activity, and keep AI under direct human supervision.

  • Autonomous Loops Retired: Tamlinux retired OpenClaw and Hermes from supported defaults. Non-deterministic autonomous AI loops consume substantial compute and electrical power with unpredictable returns.
  • Deterministic Operating System: The operating system itself must remain predictable and deterministic. AI belongs in conscious development sessions, not running as uncontrolled background processes on end-user machines.
  • Direct Human Direction: Fred directs every architectural decision, conducts design interviews, and approves all package promotions. AI agents write code, run tests, and propose refactors, but never release software autonomously.

2. Public AI Provenance (AI_PROVENANCE.md)

Tamlinux believes in total honesty regarding AI assistance:

  • Every public Tamlinux repository maintains an AI_PROVENANCE.md ledger.
  • Each entry records the date, tool/model used, user prompt, and specific changes made.
  • Respects upstream community boundaries: where projects request no AI pull requests (such as Hyprland or Void Linux), Tamlinux never submits machine-generated code to their queues.

3. Tools in the Tamlinux Development Suite

  • Claude (Anthropic): Primary reasoning model for architectural orchestration and decision planning.
  • Codex (OpenAI): High-speed code synthesis, panel ports, and test verification via delegation briefs.
  • Gemini / agy (Google DeepMind): Multimodal codebase analysis, large-scale refactoring, and survey authoring.
  • Cursor IDE: AI-powered graphical code editor, packaged as a native Arch package for Tamlinux.
