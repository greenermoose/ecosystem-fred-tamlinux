The Tamlinux Ecosystem & Choices

Welcome to the guide to the Tamlinux ecosystem. Tamlinux is an independent, continuing Linux workstation environment engineered to deliver the best possible user experience while maximizing resource efficiency, hardware longevity, and user sovereignty.

Modern Linux offers a vast landscape of possibilities. Rather than assembling a haphazard collection of tools, Tamlinux picks and chooses with deliberate care: evaluating alternatives across every layer of the operating system to construct a coherent, enduring workstation.

Core Design Pillars

Every architectural choice in Tamlinux serves six core principles:

  1. User Freedom: Licensed under GPL-3.0-or-later, protecting your right to run, study, change, and share your system.
  2. Value per Watt: Eliminating background polling, daemons, and runaway loops so your machine uses energy efficiently.
  3. Hardware Longevity: Capable of running on vintage circa-2006 computers up through modern high-end multi-display rigs.
  4. Decoupled Modularity: Following the Unix philosophy; communicating via open, standard protocols.
  5. Offline Sovereignty: Complete offline local guides and tools; zero mandatory cloud dependencies.
  6. Deterministic Human Agency: Prioritizing deterministic tools directed by humans, not opaque black boxes.
